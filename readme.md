简单的任务管理器
```
Usage: clap_todo.exe <COMMAND>

Commands:
  添加    添加一个任务 (例: td 添加 "写报告" "2025-06-01")
  列出    列出所有任务
  修改    修改任务内容 (例: td 修改 1 "新内容")
  完成    标记任务完成状态 (例: td 完成 1 true)
  删除    删除任务 (例: td 删除 1)
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
```
